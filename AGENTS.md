# Repository working agreements

- For any issue, epic, planned change, branch, pull request, handoff, or completion decision, read and follow `docs/project/WORKFLOW.md` before acting.
- When creating Git commits, use only the repository's existing Git author identity and the commit message requested or appropriate for the work.
- Never add AI tools, assistants, models, vendors, or automation as an author, co-author, contributor, signer, or attribution in commit messages, trailers, pull-request text, changelogs, or generated metadata.
- Do not add `Co-authored-by`, `Generated-by`, or similar attribution identifying the use of an AI coding assistant unless the user explicitly requests it for that specific task.
